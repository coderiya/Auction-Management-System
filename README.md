# Online Auction Management System

## Project Overview
A full-stack web application designed to facilitate online bidding and auction management. This platform allows users to view quotes, list items, place bids, and manage their accounts securely. 

## Key Features
* **User Authentication:** Secure login, registration, and password reset functionality.
* **Auction Listings:** View and manage live quotes and auction items.
* **Interactive Dashboard:** Dynamic user interface for seamless bidding and navigation.

## Tech Stack Used
* **Front-End:** HTML, CSS, JavaScript
* **Back-End:** Python (Flask)
* **Database:** SQL / SQLite
